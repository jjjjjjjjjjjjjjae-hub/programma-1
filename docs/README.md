# ONAY! интерфейс үлгісі

Бұл GitHub Pages сайты — тек оқу және UI тексеру үшін жасалған бейресми демо. Ресми ONAY сервисіне жатпайды және нақты төлемді орындамайды.

## Өзгерту

- `docs/index.html` — беттер, жазулар, батырмалар.
- `docs/style.css` — дизайн, түстер, өлшемдер, арақашықтықтар.
- `docs/app.js` — навигация және интерфейс логикасы.
- `docs/assets/` — иллюстрациялар, QR суреттері, баннерлер.

GitHub → файл → ✏️ Edit → Commit changes.

## Github Pages жариялау

Repository → Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /docs → Save.

Сайт жарияланғаннан кейін мекенжай: https://jjjjjjjjjjjjjjae-hub.github.io/programma-1/
